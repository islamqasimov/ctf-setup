# MISC — процедура (всё, что не попало в другие категории)

> Команды: `CTF_CHEATSHEET.md` → MISC. Триаж файла: `enum-file`.

## 1. Первым делом

```bash
enum-file files/whatever
```
Даже «очевидный» QR-код, файл или текст прогоняй через триаж: тип, метаданные, строки,
шаблоны флагов. Половина misc-задач решается на этом шаге.

## 2. Поддерево по формату

### 2.1 QR / штрих-код
```bash
zbarimg -q img.png
zbarimg --raw img.png
```
Не читается → попробуй `convert` (ресайз/инверсия/бинаризация), `zxing` онлайн,
повреждённые QR — восстанови по меткам через `qrazybox`.

### 2.2 Эзотерические языки
Определи по виду символов:
- `+-<>[].,` → Brainfuck (Ook!, Malbolge, Whitespace — по названию);
- странный набор слов/морфем → Piet, Befunge, JSFuck, Ook;
- «невидимые» символы → Whitespace/нулевой ширины (zero-width).

Ищи онлайн-интерпретатор по названию, либо ставь пакет (`pip install brainfuck-interpreter`).
Для Whitespace/нулевой ширины быстрее веб-декодеры.

### 2.3 Полиглоты / вложенные форматы
```bash
file --mime-type f
binwalk -e f
xxd f | head
```
Один файл может быть одновременно PNG+ZIP+PDF — ищи сигнатуры всех форматов
(`strings`/`binwalk`) и вытаскивай каждый слой.

### 2.4 Текстовые «загадки» и шифры
- Анаграммы, акростихи, первые буквы строк, регистр символов (0/1), 
  ширина/длина строк как данные;
- «Читай внимательно» → скрытый текст в нулевой ширине/Unicode-тегах;
- Unicode-трюки: `cat -A`, `python3 -c` с `unicodedata` по каждому символу.

### 2.5 PyJail / sandbox escape
Признаки: сервис принимает Python-выражение, «получи флаг, но без `os`».
```python
().__class__.__base__.__subclasses__()
# найти subprocess.Popen / os._wrap_close через __init__.__globals__
open('/flag').read()
```
Обходы: `getattr`, `__import__`, `builtins`, строковые обфускации (`chr()`), 
`globals()`, `eval`, шаблоны Jinja (см. web.md → SSTI).
Всегда смотри chmod/фильтр (`__subclasses__` могут зачистить).

### 2.6 SQL/shell jail, «вычисли мне»
Сервисы, принимающие математику/код/регулярки → это injection или logic:
сперва прочитай весь вывод ошибок, он часто содержит путь/версию.

### 2.7 Игры, боты, API
- Телеграм-бот: `@BotFather`-стиль токен в задании? Изучи API методом `getUpdates`;
- Игра с ботом (шахматы/крестики) → автомат/solver (minimax) или слабое место в random;
- REST API с флагом за условием → скрипт на Python (`requests`).

### 2.8 Blockchain / смарт-контракты
- Понять контракт: etherscan/`solc`/`cast`, найти `require`/условие победы;
- «Найди приватный ключ» → слабая генерация (ECDSA nonce reuse — `ecdsa` nonce);
- флаги в транзакциях/событиях → `cast logs`.

### 2.9 Программирование / automation
«Отправь 1000 правильных ответов за 2 секунды» → пишем скрипт (`pwntools`/`requests`/`z3`).
Никогда не решай вручную то, что нужно автоматизировать.

### 2.10 Санити / правило
Самые дешёвые очки: читай условие до конца, флаг может быть в описании, названии таска,
исходниках страницы, RSS/`robots.txt`, комментарии в коде.

## 3. Классификация «непонятного»

| Что видишь | Куда смотреть |
| --- | --- |
| Странные байты/непечатаемое | `xxd`, `strings`, `binwalk` |
| Текст, который «не текст» | кодировки (CyberChef), `enum-file` |
| Файл-многоформатник | `binwalk -e`, `file` |
| Сервис с промптом | `pwn.md` или `web.md` |
| Изображение/аудио | `forensics.md` |
| Числа/математика | `crypto.md` |

## 4. Финал

1. Если флаг не находится — перечитай условие: 8 из 10 «застрял» = пропущенный хинт.
2. Запиши на странице задания в Notion цепочку шагов; в misc это особенно важно (нет шаблонной методики).
3. Скрипт-решение → `scripts/`.
